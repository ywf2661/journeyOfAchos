# Journey of Achos — 설계 문서

> 기사 아코스가 역병을 고칠 방법을 찾아 왕국을 떠나, 시간의 마술사 아이온을 만나
> 사랑에 빠지는 3D 웹 RPG. 「어둠의 회랑」(ywf2661/dungeon-crawler)의 세계관을 빌린 **독립 신작**.

- 작성일: 2026-10-08
- 저장소: https://github.com/ywf2661/journeyOfAchos

## 1. 목표와 범위

| 항목 | 결정 |
|---|---|
| 성격 | 독립 신작. 세계관만 빌리고, 본편을 몰라도 완결되는 이야기 |
| 결말 | 연인이 되어 함께 왕국으로 출발하는 장면에서 끝. 비극(아코스의 죽음)은 암시만 |
| 핵심 플레이 | 3인칭 탐험 + 대화. 전투는 가볍게 |
| 관계 표현 | 결말은 하나. 선택지에 따라 아이온의 반응이 달라지고, 기억 조각을 모으면 엔딩 회상에 반영 |
| 분량 | 30분 내외, 지역 3개 |
| 비주얼 | CC0 로우폴리 에셋 + 조명·안개·색감으로 다크판타지 연출 |
| 기술 | Three.js + 빌드 없는 ES Module (importmap, CDN) |

**첫 버전에서 제외** (나중에 추가 가능): 모바일 터치 조작, 설정 메뉴, 다중 저장 슬롯, 인벤토리, 음성, 시계 째깍 소리 외의 사운드.

## 2. 세계관 정합성 (본편 story.md 기준)

이 게임은 본편 2장 2번 사건("아코스가 왕국 밖으로 떠나 아이온을 만나 연인이 되고, 그녀를 데려온다")의 앞부분을 다룬다.

- **아코스**: 왕국 최고의 기사. 역병을 고칠 방법을 찾아 떠난다. 병사 시절부터 낀 철 반지(본편 "낡은 병사의 반지")를 지니고 있다. 검에는 아직 이름이 없다.
- **아이온**: 왕국 밖의 시간의 마술사. 이 시점은 비극 이전이라 **눈을 가린 베일이 없다**(본편의 베일은 슬픔을 숨기려는 인상). 팔레트는 보라 + 바랜 금동, 톱니·시계 모티프.
- **마녀의 시계는 아직 없다.** 본편 설정상 왕국의 궁정 시계공과 함께 만든다.
- **역병의 시각 표현**: 검게 번지는 딱지 + 틈새의 병든 황록빛(본편 4장 기준).
- 왕의 부탁, 회랑의 탄생, 아코스와 왕자의 죽음은 **엔딩 이후의 일**이라 보여주지 않는다.
- 본편과 달리 이 게임에서는 이름(아코스, 아이온)을 직접 쓴다. 독립작이라 본편 8장의 간접 암시 원칙을 따르지 않는다.

## 3. 프로젝트 구조

```
index.html          캔버스 + 대화창/프롬프트 HTML·CSS 오버레이, importmap(Three.js CDN)
src/
  main.js           부팅, 게임 루프, 지역 전환
  world.js          지역 씬 로드(glTF), 조명·안개·색감, 트리거 지점 배치
  player.js         3인칭 이동(WASD + 마우스 카메라), 지면/경계 충돌
  story.js          순수 로직: 대화 진행, 선택지, 플래그, 기억 조각, 저장 직렬화
  combat.js         가벼운 전투
  ui.js             대화창, 선택지 버튼, 상호작용 프롬프트, 페이드
data/
  script.js         모든 대사·선택지·기억 조각 데이터
assets/             CC0 glTF 모델
tests/
  story.test.js     node --test
CREDITS.md          에셋 출처
```

**원칙**
- `story.js`는 DOM과 Three.js에 의존하지 않는 순수 모듈이다. 대사 수정은 `data/script.js`만 건드린다.
- 상호작용은 **트리거 지점** 하나로 통일한다. 지역마다 사람·사물·장소에 트리거를 두고, 가까이 가서 E를 누르면 대화 노드가 시작된다. 기억 조각, 전투 시작, 지역 이동도 전부 대화 노드의 `do`로 일으킨다.
- 실행은 정적 파일 서버만 있으면 된다(GitHub Pages 배포 가능).

## 4. 지역과 스토리 흐름

### 지역 1 — 역병의 왕도 → 성 밖의 길 (약 8분, 튜토리얼)
- 밤의 왕도. 거리에 역병의 흔적이 있다.
- 트리거: 아코스 휘하의 병사들, 숙소의 갑주 걸이("그가 돌아오면, 이 자리에"), 병상의 어린 왕자("돌아오면 목마 태워 주세요"), 성문 경비병, 왕의 배웅.
- 성문 밖 황야에서 역병에 먹힌 짐승과 가벼운 전투를 두어 번 치르며 조작을 익힌다.
- 끝: 여행자에게서 "시간을 멈추는 마술사가 산다는 골짜기" 소문을 듣고, 멀리서 들리는 시계 소리를 따라간다 → 지역 2.

### 지역 2 — 멈춘 계절의 골짜기, 아이온의 거처 (약 17분, 본편)
- 시간이 군데군데 멈춘 곳: 공중에 멈춘 낙엽, 얼어붙은 폭포, 탑 모양의 관측소.
- **만남**: 아이온은 처음에 거절한다. "시간은 병을 고치지 못한다. 멈출 수 있을 뿐."
- **함께 지내는 며칠**(`day` 1~3): 저녁에 탑에서 아이온과 대화하면 다음 날로 넘어간다. 날마다 조명(아침·노을·밤)과 활성 트리거가 바뀐다.
- **기억 조각 5개**(선택 수집):
  1. 멈춘 폭포 아래 산책
  2. 탑 꼭대기에서 별 보기
  3. 고장 난 시계 고치기
  4. 병사의 반지 이야기
  5. 그녀의 이름을 처음 부르는 순간
- **전투 명장면**: 역병 짐승 무리가 골짜기를 덮친다. 아이온이 시간을 멈추고, 멈춘 시간 속에서 아코스가 싸운다. "그녀의 힘이라면 왕국을 구할 수도 있겠다"는 희망으로 이어진다.
- 선택지에 따라 아이온의 반응 대사와 일부 기억 조각의 등장 여부가 달라진다.

### 지역 3 — 새벽의 출발 (약 5분, 엔딩)
- 골짜기 어귀의 다리. 아이온이 "같이 가겠다"고 한다. 이유를 말하는 대사는 앞의 선택에 따라 갈린다.
- 함께 왕국 쪽 지평선으로 걸어가면, 모은 기억 조각이 회상으로 흐른다(모은 것만).
- 마지막 암시: 아코스가 손목의 검은 딱지를 장갑으로 가린다. 아이온은 알아채지 못한다. 페이드아웃.

## 5. 시스템 상세

### 5-1. 이동과 카메라
- WASD 이동, Shift 달리기, 마우스 드래그로 3인칭 카메라 회전.
- 물리 엔진 없음. 지면 높이는 아래 방향 레이캐스트로, 장애물은 원형 충돌체 목록으로, 지역 바깥은 경계로 막는다.

### 5-2. 대화와 선택지
대사 노드 형식:

```js
{ id: 'n1', who: '아이온', text: '…', next: 'n2' }
{ id: 'n2', choices: [{ text: '…', next: 'n3', set: 'kind' }] }
```

노드 필드:
- `who`, `text`: 화자와 대사
- `next`: 다음 노드 id. 없으면 대화 종료
- `choices`: 선택지 배열. 각 선택지는 `text`, `next`, 선택적으로 `set`, `if`
- `if`: 플래그 조건(`'kind'` 또는 부정 `'!kind'`). 노드에 붙으면 조건이 거짓일 때 그 노드를 표시하지 않고 `next`로 넘어간다. 선택지에 붙으면 조건이 거짓일 때 그 선택지를 목록에서 숨긴다
- `set`: 켤 플래그
- `memory`: 획득할 기억 조각 id
- `do`: 게임 쪽 효과 — `combat:<id>`, `nextDay`, `region:<n>`, `ending`

표시: 화면 하단 HTML 대화창, 글자가 한 자씩 출력, 클릭 또는 Space로 넘김. 폰트는 나눔명조(Google Fonts).

### 5-3. 기억 조각
- 특정 날, 특정 장소의 트리거로 열린다. 일부는 선택지 플래그가 있어야 나타난다.
- 획득 시 화면 구석에 작은 연출을 띄운다. 엔딩 회상에는 모은 것만 나온다.

### 5-4. 전투
- 클릭: 베기(전방 부채꼴 범위 판정). Space: 짧은 회피 대시(무적 시간 있음).
- 아코스 체력 5칸, 적은 2~3번 맞으면 쓰러진다.
- 체력이 다 떨어지면 게임 오버 없이 해당 전투만 다시 시작한다.
- 시간 정지 장면: 적이 멈추고 화면이 보라빛 흑백으로 바뀐다. 제한 시간 안에 모두 벤다. 시간 초과 시 그 장면을 다시 시작한다.

### 5-5. 저장
- 지역 진입 시와 대화 종료 시 localStorage에 `{ region, day, flags, memories }`를 자동 저장한다.
- localStorage 접근이 실패하면 저장 없이 계속 진행한다(시크릿 모드 등).
- 타이틀 화면: 이어하기 / 새로 시작.

### 5-6. 에셋과 사운드
- Quaternius CC0 캐릭터(걷기·달리기·공격 애니메이션 포함)와 자연·중세 소품 팩. 구체적인 팩은 구현 계획에서 확정하고 `CREDITS.md`에 기록한다.
- 사운드는 WebAudio로 합성한 시계 째깍 소리 하나만 넣는다.

## 6. 테스트

### 자동 (`node --test`, 의존성 없음)
- `story.js`: 노드 이동, 선택지 분기, `if` 조건, `set` 플래그, `memory` 획득, 저장 직렬화/복원.
- 스크립트 무결성: `data/script.js`의 모든 `next`가 실제로 있는 노드를 가리킨다.
- 완주 가능성: 모든 선택지 조합에서 `ending` 노드에 도달할 수 있다.

### 수동 (브라우저, 로컬 정적 서버)
지역마다 체크리스트: 이동, 충돌, 트리거 작동, 대화 표시, 전투 재시작, 지역 전환, 새로고침 후 이어하기.

## 7. 완료 기준

1. 새 게임으로 시작해 지역 3개를 거쳐 엔딩까지 끊김 없이 진행된다(약 30분).
2. 기억 조각 0개와 5개 모두 엔딩이 정상 동작하고, 회상 장면은 모은 개수에 따라 달라진다.
3. 중간에 새로고침해도 이어하기가 된다.
4. 최신 Chrome과 Edge, 일반 노트북에서 60fps 목표, 최소 30fps.
5. 모든 에셋이 CC0이고 `CREDITS.md`에 출처가 있다.
6. 자동 테스트가 전부 통과한다.
